API de Gestão de Clientes e Notas Fiscais

Demo funcional

API REST com autenticação JWT para cadastro de clientes e emissão/controle de notas fiscais. Modelagem reflete prática contábil real: notas fiscais nunca são deletadas, apenas canceladas, preservando o histórico. Documentação interativa gerada automaticamente e 19 testes automatizados cobrindo as regras de negócio.

  • FastAPI
